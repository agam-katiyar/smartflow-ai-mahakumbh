## 🎯 Problem Statement
Mahakumbh 2028 — the world's largest human gathering with **450 million pilgrims** in Prayagraj — faces unprecedented challenges in crowd mobility, parking management, and real-time traffic routing across a 3,200-hectare mela ground.

## 💡 Solution
SmartFlow AI combines **real-time crowd density monitoring**, **AI-powered route optimization**, **smart parking allocation**, and a **natural language AI mobility advisor** to enable both pilgrims and authorities to make intelligent, data-driven decisions.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🗺️ **Live Congestion Heatmap** | 18-zone interactive SVG map with real-time density updates every 4 seconds |
| 🧭 **Smart Route Recommender** | AI-optimized path with congestion score, travel time & alternate route |
| 🅿️ **Parking Optimizer** | Live occupancy, shuttle frequency, walking distance with AI recommendations |
| 🤖 **AI Mobility Advisor** | Natural language Q&A powered by Gemini 2.0 Flash with Mahakumbh context |
| 🔮 **Congestion Predictions** | 30-min, 1-hour, 3-hour forecasts using trend analysis |
| 🚨 **Incident Command Board** | Real-time SOS alerts, dispatch system, and crowd broadcast terminal |

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 + Tailwind CSS (glassmorphism dark theme)
- **Charts**: Recharts (area, bar, line charts)
- **Maps**: Custom SVG vector map (Prayagraj zones)
- **AI**: Google Gemini 2.0 Flash API
- **Icons**: Lucide React
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/smartflow-ai.git
cd smartflow-ai

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your Gemini API key to .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 🔑 Environment Variables

GEMINI_API_KEY=your_gemini_api_key_here
